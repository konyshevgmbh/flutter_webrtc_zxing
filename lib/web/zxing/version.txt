Files in this directory are pre-built from zxing-cpp and published to npm.
They must be updated manually when upgrading zxing-wasm.

  lib/web/zxing/index.js        — ZXing JS glue (ESM, imports ../share.js)

To update:
  1. Check the latest version: https://www.npmjs.com/package/zxing-wasm
  2. Download new files (replace <VERSION> with the target version):
       curl -L https://cdn.jsdelivr.net/npm/zxing-wasm@<VERSION>/dist/es/share.js         -o lib/web/share.js
       curl -L https://cdn.jsdelivr.net/npm/zxing-wasm@<VERSION>/dist/es/full/index.js    -o lib/web/zxing/index.js
       curl -L https://cdn.jsdelivr.net/npm/zxing-wasm@<VERSION>/dist/full/zxing_full.wasm -o lib/web/zxing/zxing_full.wasm
  3. Update the version line at the top of this file.
  4. Check the zxing-wasm changelog for any breaking API changes in readBarcodesFromImageFile.
